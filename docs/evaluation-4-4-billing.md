# B3-1 동료평가 4-4 — AWS 비용 원인 추적

## 평가 질문

AWS Billing 화면에서 예상하지 못한 비용이 발생했다면, 어떤 클라우드 자원부터 의심하고 어떻게 원인을 추적하고 정리할지 설명할 수 있는가?

## 실제 확인 사례 (2026-11-19, AWS 서울 리전)

AWS Billing에서 2026년 11월 사용료가 약 **USD 1.34** 계산된 것을 발견했다. 처음에는 리전이 다르거나 보안 그룹에 등록한 집/아카데미 IP 두 개 때문에 과금된 것으로 추측했으나, 실제 청구 상세 항목을 확인하여 구분했다.

| 과금 자원 | 청구 화면의 사용량·단가 | 계산된 사용료 | AWS Free Tier 크레딧 |
| --- | --- | ---: | ---: |
| EC2 Linux t3.micro | 70시간 × $0.013/시간 | $0.91 | EC2/EBS 합계에서 차감 |
| EBS gp3 저장 공간 | 0.778 GB-month × $0.0912/GB-month | $0.07 | EC2/EBS 합계 **−$0.98** |
| VPC 공인 IPv4 주소 | 시간당 $0.005, 두 사용량 구간 | $0.36 | **−$0.36** |
| **위 항목 합계** | | **$1.34** | **−$1.34** |

**결과:** 이 화면에서 확인한 EC2/EBS와 VPC 공인 IPv4 사용료는 각각 AWS Free Tier 크레딧으로 상쇄됐다. 여기의 $1.34는 크레딧 적용 전 계산된 사용료이며, 전체 계정의 최종 결제액이 $1.34라고 단정하지 않는다. 월말 확정 청구액은 별도로 확인해야 한다.

## 증상 → 가설 → 검증 → 조치 → 결과 → 재발 방지

1. **증상:** 비용 요약에 약 $1.34가 표시되어 예상하지 못한 과금이 걱정됐다.
2. **가설:** EC2 구동, EBS 저장 공간, 공인 IPv4 주소 중 하나가 원인일 수 있다고 추측했다.
3. **검증:** Billing → 청구서 → 서비스별 요금에서 서울 리전별 사용량과 단가를 펼쳐 EC2 $0.91, EBS $0.07, 공인 IPv4 $0.36을 확인했다. 'No Region'의 AWS Free Tier 차감 내역도 확인했다.
4. **추가 검증:** 서울 리전 EC2 → 탄력적 IP 주소 목록이 비어 있음을 확인했다. 별도의 EIP가 생성되었다는 증거는 없으며, EC2의 자동 할당 공인 IPv4 주소에도 요금이 발생할 수 있다. 보안 그룹의 아카데미/집 IP **허용 규칙**은 EC2에 공인 IP를 두 개 할당한다는 뜻이 아니다.
5. **조치:** 원인 확인과 증거 보존을 진행했다. **EC2·EBS·네트워크 자원은 평가 시연 중이므로 아직 삭제하지 않았다.**
6. **결과:** 사용료가 어떤 서비스에서 계산됐는지, 해당 항목에 무료 티어 크레딧이 적용됐는지를 확인했다.
7. **재발 방지:** 평가 종료 후 이번 미션 자원만 선별해 정리하고, `docs/cleanup-checklist.md`에 삭제 또는 미생성 여부와 증거를 기록한다. AWS Billing과 예산 알림을 주기적으로 확인한다.

## 평가자에게 짧게 설명하기

> 실습 중 Billing에 약 $1.34 사용료가 나타나 EC2와 네트워크 자원을 의심했습니다. 서비스별 요금을 펼쳐 EC2 70시간 사용료 $0.91, EBS $0.07, 공인 IPv4 주소 $0.36임을 확인했습니다. 이어 AWS Free Tier 차감 내역을 확인해 이 세 항목의 사용료가 상쇄된 것도 검증했습니다. 아직 실습 시연 중이라 자원을 삭제하지 않았으며, 종료 후 EC2·EBS·네트워크 자원을 체크리스트에 따라 정리하겠습니다.

## 증빙과 정리

- 증빙 출처: 2026년 11월 AWS Billing → 청구서 → 서비스별 요금 화면의 EC2/EBS 및 VPC Public IPv4 상세 내역.
- 관련 문서: [AWS 리소스 정리 체크리스트](cleanup-checklist.md)
- **비용 원인 추적과 실제 자원 삭제는 별도 단계이다.** 삭제 완료라고 기재하지 않는다.

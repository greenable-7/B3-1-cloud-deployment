## 2. 실제 작업 흐름

1. EC2 `cdy` 실행 중 및 연결된 루트 EBS 정보를 캡처.
2. EBS `vol-0e71dfa6e67864031`의 **종료 시 삭제 = 예** 확인.
3. EC2 `i-081121aca74954e4e` **인스턴스 종료(삭제)** → 목록에서 **종료됨** 확인.
4. EC2 → Elastic Block Store → 볼륨에서 해당 EBS ID 검색 → 결과 없음 확인.
5. VPC `b3-1-vpc`와 기본 VPC `172.31.0.0/16` 구분.
6. VPC 삭제 확인창에 **IGW·라우트 테이블·보안 그룹·퍼블릭 서브넷** 4개 자원의 ID 표시 확인.
7. **VPC 삭제 실행** → `b3-1-vpc 및 4 기타 리소스를 삭제했습니다` 성공 알림 확인. 기본 VPC는 목록에 남아 있음.

## 3. 비용 및 마무리 확인

- 이전 Billing 확인: EC2 $0.91, EBS $0.07, 공인 IPv4 $0.36의 계산 사용료가 AWS Free Tier 크레딧으로 상쇄됐음(당시 화면 기준).
- 정리 직후 청구 화면은 반영 지연이 있을 수 있으며 **최종 비용 0원 여부는 재확인 필요**.
- 실습에서 만든 키 페어 및 별도 스냅샷 등 **추가 잔여 자원은 확인 필요**.
- 재구성 시 새로운 VPC/EC2/네트워크 자원은 **새 ID로 생성**되므로 이 삭제 완료 기록과 섞지 않음.

## 4. 평가에서 설명할 내용
